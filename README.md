## 🧠 Development Philosophy

> **문제를 정확히 이해하고, 상황에 맞는 기술과 구조를 선택합니다.**

실무에서는 실제 사용자가 이용하는 서비스를 운영하며 예상하지 못한 사용 패턴과 성능 문제를 직접 분석하고 해결했습니다.

개인 프로젝트에서는 주어진 환경과 제약을 고려하여 GitHub Contents API를 활용한 콘텐츠 관리, JWT 기반 인증, App Router 기반 라우팅 구조 등을 직접 설계하고 구현했습니다.

단순히 새로운 기술을 사용하는 것보다 **왜 해당 기술과 구조를 선택했는지, 어떤 트레이드오프가 있었는지를 설명할 수 있는 개발**을 지향합니다.
